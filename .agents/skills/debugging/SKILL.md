# Systematic Debugging Skill

## Purpose
Diagnose and resolve software errors systematically through evidence-based root-cause analysis rather than speculative trial-and-error edits.

## Debugging Workflow
```text
1. Reproduce: Replicate the failure reliably with a minimal failing test or reproduction script.
2. Observe: Inspect exact error stack traces, execution logs, and network payloads.
3. Hypothesize: Formulate specific, testable hypotheses regarding the underlying cause.
4. Verify Hypothesis: Check code paths, variable states, and database records against the hypothesis.
5. Fix & Regress: Apply the minimal necessary fix and execute full regression test suites.
```
