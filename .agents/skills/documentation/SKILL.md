# Technical Documentation Skill

## Purpose
Maintain accurate, comprehensive, and up-to-date engineering documentation across the AquaFlow repository.

## Documentation Artifacts & Guidelines
1. **PRD (`docs/PRD.md`)**: Defines high-level product goals, feature sets, user personas, and release milestones.
2. **Architecture (`docs/ARCHITECTURE.md`)**: Documents layer interactions, hexagonal ports, and external adapter boundaries.
3. **ADRs (`docs/adr/ADR-XXX-<title>.md`)**: Records context, options, decision, and consequences for architectural changes.
4. **Traceability Matrix (`docs/requirements/requirements-traceability.md`)**: Maps requirements to implementation artifacts and test suites.
5. **Data Classification & Threat Model**: Documents security classifications and threat mitigations.
